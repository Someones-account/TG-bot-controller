# TG-bot-controller 
### Project consists of two parts: the bot manager and the bot itself.
##### Functionality of the bot:
Available commands:
- `/start` - starts the bot
- `/help` - display available commands
- `/ban` - bans user by replying to message
- `/ai` - prompt LLM (no history)
- `/chat` - start/continue a chat session with LLM (history unique to each user)
- `/context_chat` - prompt LLM (with history of messages in chat)
- `/vision` - prompt AI vision model to describe a photo (if no parameters provided, just replies with a text in the photo)
